MCalendar Agent – Agentic AI Testing System

  • Description: MCalendar Agent is an Agentic AI system built from scratch that automates the full software testing lifecycle. It fetches GitHub issues, analyzes commit code changes, generates and runs test cases, reviews results, auto-fixes failing tests, and produces summary reports — powered by multi-provider LLM support.
  • Github URL: Private Repository

Key Features:

  • GitHub Issue Analysis – Fetches and analyzes GitHub issues to understand requirements and generate relevant test cases.
  • Commit Code Change Detection – Analyzes code diffs to determine when new or updated tests are needed, and auto-generates them.
  • Automated Test Generation – Generates Playwright test cases based on issue context and code changes.
  • Test Execution & Reporting – Runs generated tests and produces detailed summary reports with pass/fail status.
  • Review Agent – Identifies failing test cases and automatically generates fixes to improve test reliability.
  • Multi-Provider LLM Support – Integrates Anthropic, OpenAI, Google, and OpenRouter for flexible and cost-effective model selection.
  • End-to-End Automation – Full pipeline from issue analysis to test report without manual intervention.

Technologies Used:

  • Node.js – Backend runtime for the AI pipeline.
  • React.js – Frontend for configuration and report viewing.
  • Playwright – End-to-end testing framework for test execution.
  • GitHub API – Issue fetching and commit analysis.
  • Anthropic Claude – LLM provider for test generation and review.
  • OpenAI API – LLM provider for test generation and review.
  • Google Gemini – LLM provider for test generation and review.
  • OpenRouter – Multi-model gateway for flexible LLM access.
  • RESTful APIs – Communication between frontend and backend agents.
