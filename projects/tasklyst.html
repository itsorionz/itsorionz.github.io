Tasklyst- Job Marketplace Platform - .Net Core and React

  • Description: Tasklyst is a modern job marketplace that connects employers with job seekers across all skill levels, from daily wage workers to professional service providers. The platform enables users to post jobs, search opportunities, apply instantly, and communicate efficiently in a secure environment.
  • Github URL: Private Repository

Key Features:

  • Job Search & Filtering – Search jobs by category, location, salary, experience, and keywords.
  • Employer Dashboard – Employers can post jobs, manage listings, review applications, and hire candidates.
  • Job Seeker Profiles – Create professional profiles, upload resumes, manage skills, and track applications.
  • Application Management – Apply for jobs online and monitor application status in real time.
  • Real-Time Notifications – Receive instant updates for new jobs, applications, interview requests, and hiring activities.
  • Secure Authentication – User registration, login, JWT authentication, and role-based authorization for Job Seekers, Employers, and Admins.
  • Admin Management – Manage users, job listings, reported content, categories, and platform settings.
  • Responsive Design – Fully optimized for desktop, tablet, and mobile devices.
  • Performance Optimization – Redis caching improves application speed and reduces database load.
  • Scalable REST API – Clean RESTful architecture supporting future mobile applications and third-party integrations.

Technologies Used:

  • ASP.NET Core Web API – Backend REST API and business logic.
  • React.js – Modern frontend for a fast and interactive user experience.
  • PostgreSQL – Primary relational database for storing users, jobs, applications, and platform data.
  • Redis – High-performance distributed caching for improved response times.
  • Entity Framework Core – ORM for efficient database access and migrations.
  • JWT Authentication – Secure user authentication and role-based authorization.
  • RESTful APIs – Communication between frontend and backend.
  • Bootstrap / Tailwind CSS – Responsive and modern UI components.
  • Git & GitHub – Version control and collaborative development.
