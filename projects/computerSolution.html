Computer Solution- .Net Core and Razor

  • Description: Developed a complete computer retail and service management solution using ASP.NET Core MVC and Razor Views. The system integrates Point of Sale (POS), Service Care, and Accounts modules into a single platform, enabling businesses to manage product sales, repair and warranty services, customer payments, inventory, and financial operations efficiently. It also includes an e-commerce platform where customers can browse products, place online orders, and book service requests, providing functionality.
  • Github URL: Private Repository

Key Features:

  • Multi-Module Dashboard – Developed dedicated dashboards for System Admin, General Admin, Accounts, POS, and Care modules, providing real-time insights, KPIs, and module-specific reports.
  • System Administration – Manage users, roles, permissions, branches, system settings, product categories, brands, and application configurations with role-based access control.
  • General Administration – Manage customers, suppliers, products, inventory, purchase orders, stock transfers, warehouse operations, and overall business activities.
  • POS (Point of Sale) – Process retail sales, generate invoices, apply discounts, manage returns, print receipts, and support multiple payment methods with real-time stock updates.
  • Care & Service Management – Register service requests, manage repair jobs, warranty claims, technician assignments, complaint tracking, service delivery, and customer notifications.
  • Accounts Management – Handle customer payments, supplier payments, cash and bank transactions, vouchers, ledgers, expenses, income, and financial reconciliation.
  • E-Commerce & Online Booking – Customers can browse products, place online orders, check product availability, and book repair or warranty services through the web portal.
  • Inventory & Warehouse Management – Monitor stock levels, stock transfers, purchase receipts, low-stock alerts, serial number tracking, and warehouse inventory.
  • Sales & Purchase Management – Manage quotations, purchases, sales orders, invoicing, payment history, and order fulfillment.
  • Warranty & Claim Management – Track warranty registrations, product claims, repair status, delivery, and complete claim lifecycle management.
  • Advanced Search & Reporting – Search using invoice number, serial number, claim number, customer name, or mobile number, with comprehensive sales, inventory, service, and financial reports.
  • Authentication & Security – Implemented secure authentication, role-based authorization, and permission management across all modules.
  • Responsive User Interface – Built responsive Razor View pages optimized for desktop, tablet, and mobile devices.

Technologies Used:

  • ASP.NET Core MVC – Backend framework for developing business logic and enterprise modules.
  • Razor Views – Server-side rendering for responsive and dynamic user interfaces.
  • C# – Implemented application logic, services, controllers, validation, and business workflows.
  • SQL Server (T-SQL) – Database design, stored procedures, views, functions, triggers, and performance optimization.
  • Entity Framework Core – ORM for efficient database operations and data access.
  • Bootstrap, HTML5, CSS3 & JavaScript – Responsive and interactive user interface development.
  • jQuery & AJAX – Asynchronous operations, dynamic content loading, and enhanced user experience.
  • Git & GitHub – Source code management and collaborative development.
